# WUGAN 第二方案 1.0.0

独立 WordPress 主题：`wordpress/wugan-second`。第一方案 `wugan-studio` 2.0.2 保持不变。本版本未部署到 wugan.net。

## 设计与内容来源

- 研究用户上传的“第二案例参考代码.zip”：八份 Word 文档中的 HTML，含首页内嵌 CSS。参考其全宽实景主视觉、深浅交替区段、横向产品列表、定制开发流程和独立内页结构。
- 未直接使用参考网站的程序、图片、商标、统计数字、客户背书或联系信息；原站外部资源不完整，因此不是逐像素复制。
- WUGAN 既有公司资料文案库和已经确认的产品资料是内容基础。使用自有 Logo、车间、展厅、团队、客户到访与产品照片。
- 首要受众：已有产品线、准备开发运动系列的成熟中小品牌；兼顾初创品牌。
- MOQ：单款单色 300 件，最多混 4 个尺码。样品 USD 15 起；打样 7 天起；常规生产 15 天起。具体条件按规格、材料和确认排期报价。
- 不使用资料中相互冲突的面积、人数、产量数字；不将供应商材料认证或历史报告描述成全厂、全产品当前认证。

## 交付内容

17 个内容页（含首页、产品入口、内裤、袜子、OEM/ODM、定制、面料、样品、工厂、关于、质量、合作、品牌开发、资源、FAQ、联系、隐私）及 8 个独立产品页。

提供三组桌面悬停/键盘下拉菜单、手机菜单、产品横向浏览、分类与搜索、产品图库、WhatsApp、下载、询盘与样品申请。WordPress 后台可编辑页面、产品字段和替换图片。

语言入口：英文原文，其他语言为明确标示的 Google Translate 外部入口；安装并配置 Polylang 后可使用原生翻译链接。本版本没有交付人工翻译、多语言 SEO 页面或按国家强制跳转。

## 给部署窗口

1. 拉取本版本提交，核对 `wordpress/second-scheme-release.json`。不要误用第一方案的 `wordpress/release.json`。
2. 备份正式数据库、上传目录、插件和当前主题；优先在独立暂存站预演。
3. 安装 `review/wugan-second-v1.0.0.zip`，配合既有 `wugan-inquiries` 1.1.2 插件。主题安装包不是离线预览包。
4. 激活 WUGAN Second Scheme。在外观中的 Wugan setup 导入内容。空白站可直接导入；已有第一方案页面时，只有明确选择 release upgrade 才会替换这些页面正文。先确认备份，不能仅切换主题就认为页面已升级。
5. 同一个 WordPress 数据库的页面由各主题共享。需要同时保留两方案的可浏览版本时，应使用两套站点/数据库，而不是在同一站反复导入。产品和询盘不会被导入器清空。
6. 保存固定链接；配置 SMTP、发送真实测试询盘并核对邮箱。检查缓存排除后台和表单处理地址，避免缓存 nonce。
7. OKKI 尚未连接，需实际 API 文档、授权和字段映射后单独验收。不要把预留 hook 描述成已对接。
8. 上线前核对证书有效期/适用范围、联系方式、隐私政策、真实袜子 SKU 资料以及手机导航。当前袜子页为开发项目入口，不虚构缺失的 SKU 参数。

## 预览

解压 `review/WUGAN-Second-Scheme-1.0.0-preview.zip` 后打开其中 `index.html`，无需安装 WordPress。离线表单只准备邮件草稿，不发送或保存询盘；翻译入口需要联网。

云端隔离测试服务为 `http://localhost:8092`，不是用户电脑可访问的公网地址。正式发布由部署窗口完成。

## 验证

- `node scripts/check-second-scheme.cjs`：25 路由、6 种宽度、图片、溢出、三个悬停菜单、手机导航、语言入口、产品横向浏览、404 与脚本错误。
- `WUGAN_TEST_URL=http://localhost:8092 node scripts/check-studio-form.cjs`：真实保存询盘、样品预选、无效 nonce 拒绝、未验证回执拒绝；测试站禁止外发邮件。
- 预览导出使用 `scripts/export-wordpress-review.mjs`，支持 `WUGAN_TEST_URL`、`WUGAN_SITE_DATA`、`WUGAN_PREVIEW_DIR`、`WUGAN_PREVIEW_LABEL`；默认值仍保留第一方案。

未完成的生产验收不能由本地测试替代：真实邮箱投递、OKKI、完整多语言内容、正式服务器缓存/安全和证书更新。
